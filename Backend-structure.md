# Backend Structure

## viva homes ports
* backend - 3000
* mobile - 3001

## Project Structure

Backend - Nestjs
Web - Nextjs
Admin - Nextjs
Mobile - React native

## Roles

users(clients)

- views available homes
- writes reviews about the home
- views the profile of the agents
- able to rate agents
- waitlist function

Agents(Brokers)

- Posts available homes
- are certified by viva homes
- defines the location he is currently located on

Admin

- only available on web
- monitors the system
- system based admin actions

Guardian

- monitors agents(brokers)
- blocks illegal agents(fire them and take away their cirtificate)
- gives cirtificate to trusted agents(brokers)

Home Owners

- contact best brokers they choose to trust and sell or loan their property through them
- can post by themselves
- can write review and rate brokers
